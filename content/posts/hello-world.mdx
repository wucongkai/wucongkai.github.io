这是一篇示例文章。你可以把它改成建站随笔、自我介绍，或者最近正在学习的一件事。

## 从一小段记录开始

个人主页可以是一个慢慢生长的地方。先记录一个问题、一段代码或一本书里的想法，再把它们整理成自己愿意反复阅读的内容。

写笔记时，可以保留三个部分：

1. **问题是什么**：用自己的话描述最初的不解。
2. **我是怎样理解的**：写下推导过程和具体例子。
3. **还有什么没弄懂**：为下一次学习留一个入口。

> 不必一次写得完整。先留下一个以后可以继续思考的起点。

## 一个最小的例子

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"

print(hello("world"))
```

代码可以很短，解释可以更具体：这个函数接收一个名字，返回一段问候；最后一行把结果打印出来。
