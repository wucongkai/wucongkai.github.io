这篇示例展示了文章中常见的几种内容。写自己的笔记时，选择真正有用的部分即可。

## 先提出问题

开头先说明这篇文章想解决什么。与其从一串名词开始，不如给出一个具体场景，再解释为什么需要这些概念。

## 用例子支持解释

一段代码只做一件事，阅读起来更容易。下面的函数把数组中的每个数字加倍：

```javascript
function double(numbers) {
  return numbers.map((number) => number * 2);
}

double([1, 2, 3]); // [2, 4, 6]
```

需要比较时，表格可以把信息放在一起：

| 内容 | 适合记录什么 |
| --- | --- |
| 项目 | 解决的问题、使用方式和实现取舍 |
| 学习笔记 | 概念、推导、实验和疑问 |
| 阅读记录 | 书中的观点与自己的理解 |

## 留下可继续的问题

- 这个解释有没有遗漏边界条件？
- 换一个输入，结果是否仍然成立？
- 能否用更小的例子验证结论？

记录这些问题，下次回来时就知道从哪里继续。
